# SimpleComputer

Эмулятор 15-битного аккумуляторного процессора с консольным интерфейсом: оперативная
память, регистр флагов, кеш, таймер тактов и полный цикл выполнения команд. В комплекте
ассемблер и транслятор языка Simple Basic.

```
program.sb → sbt → program.sa → sat → program.o → sc
```

## Сборка

Нужны Linux (или WSL), `gcc`, `g++` и `make`:
```bash
make
```

| Программа | Что делает |
|---|---|
| `console/sc` | сам процессор с интерфейсом |
| `simpleassembler/sat` | Simple Assembler → машинный код |
| `simplebasic/sbt` | Simple Basic → Simple Assembler |
| `console/font` | генерирует шрифт больших цифр `font.bin` |

Библиотеки:

| Каталог | Назначение |
|---|---|
| `mySimpleComputer/` | память, регистры, кеш, кодирование команд |
| `myTerm/` | управление терминалом через escape-последовательности |
| `myBigChars/` | псевдографика и большие символы |
| `myReadKey/` | неканонический ввод клавиш и чисел |

## Пример

```bash
./simplebasic/sbt factorial.sb factorial.sa
./simpleassembler/sat factorial.sa factorial.o
./console/sc
```

В `sc` нажмите `l`, введите `factorial.o`, затем `r`. Программа запросит `N` в панели
IN–OUT. `sc` запускается из корня репозитория, потому что читает `font.bin` из текущего
каталога (другой путь можно передать аргументом: `./console/sc путь/к/font.bin`).

## Процессор

- **Память:** 128 ячеек по 15 бит.
- **Числа:** знак + модуль (бит 14 — знак, 14 бит — модуль), диапазон −16383…16383. При
  переполнении выставляется флаг `P`.
- **Команда:** `0 | 7 бит код операции | 7 бит адрес`.
- **Кеш:** 5 строк по 10 ячеек, вытеснение LRU. Промах стоит 10 тактов простоя.
- **Такт:** 0,5 с (таймер `SIGALRM`), поэтому в режиме `r` выполнение видно по шагам.

### Флаги

| Флаг | Значение |
|---|---|
| `P` | переполнение |
| `0` | деление на ноль |
| `M` | выход за границы памяти |
| `T` | игнорирование тактов (процессор остановлен) |
| `E` | неверная команда |

### Команды

| Код | Команда | Действие |
|---|---|---|
| 00 | `NOP` | ничего |
| 01 | `CPUINFO` | информация об авторе |
| 0A | `READ a` | ввод числа с клавиатуры в ячейку `a` |
| 0B | `WRITE a` | вывод ячейки `a` в панель IN–OUT |
| 14 | `LOAD a` | аккумулятор ← `a` |
| 15 | `STORE a` | `a` ← аккумулятор |
| 1E | `ADD a` | аккумулятор += `a` |
| 1F | `SUB a` | аккумулятор −= `a` |
| 20 | `DIVIDE a` | аккумулятор /= `a` |
| 21 | `MUL a` | аккумулятор *= `a` |
| 28 | `JUMP a` | переход на `a` |
| 29 | `JNEG a` | переход, если аккумулятор < 0 |
| 2A | `JZ a` | переход, если аккумулятор = 0 |
| 2B | `HALT` | останов |
| 33 | `NOT a` | `a` ← побитовое НЕ аккумулятора |
| 34 | `AND a` | аккумулятор &= `a` |
| 35 | `OR a` | аккумулятор \|= `a` |
| 36 | `XOR a` | аккумулятор ^= `a` |
| 37 | `JNS a` | переход, если аккумулятор > 0 |

## Интерфейс `sc`

| Клавиша | Действие |
|---|---|
| стрелки | выбор ячейки памяти |
| `Enter` | редактировать ячейку |
| `F5` / `F6` | редактировать аккумулятор / счётчик команд |
| `l` / `s` | загрузить / сохранить память в файл |
| `r` | запуск |
| `t` | выполнить одну команду |
| `i` | сброс |
| `Esc` | выход |

Числа вводятся и показываются в формате процессора: знак и две 16-ричные половины модуля по
7 бит. Например, `+0007` = 7, `-0005` = −5, `+2730` = 5040.

## Simple Assembler

Одна строка — одна ячейка памяти:
```
<адрес> <КОМАНДА> <операнд> [; комментарий]
<адрес> = <±XXXX>           [; комментарий]
```

```
0 READ 127
1 LOAD 127
2 MUL 126
3 STORE 125
4 WRITE 125
5 HALT 0
126 = +0002 ; константа 2
```

## Simple Basic

Строки с номерами, переменные — одна заглавная буква `A`–`Z`:

| Оператор | Пример |
|---|---|
| `REM` | `10 REM комментарий` |
| `INPUT` | `20 INPUT N` |
| `OUTPUT` | `90 OUTPUT F` |
| `LET` | `70 LET F = F * C + 1` — `+ - * /` с обычным приоритетом, без скобок |
| `IF ... GOTO` | `50 IF C = N GOTO 90` — сравнения `<`, `>`, `=` |
| `GOTO` | `80 GOTO 50` |
| `END` | `100 END` |

Пример — [`factorial.sb`](factorial.sb).

## Компиляция из COOL

Программы для процессора можно писать и на подмножестве языка COOL: компилятор `cool-sc`
из репозитория compilers (`semantic-analyzer/`) переводит их в Simple Assembler.
